# ✈️ Airline Management System

An **Airline Management System** built using **Java, Swing, MySQL, and React** that helps manage airline operations efficiently — including flights, passengers, bookings, and staff.  
This project demonstrates the integration of **frontend (React + Java Swing)** and **backend (Java + MySQL)** for a complete full-stack airline application.

---

## 🚀 Features

### 🧭 Admin Features
- Add, update, and delete flight details  
- Manage passengers, staff, and bookings  
- View daily, weekly, and monthly reports  

### 👥 User Features
- Register and log in securely  
- Search flights by destination, date, and price  
- Book, modify, and cancel tickets  
- View booking history and ticket status  

### ⚙️ System Features
- MySQL database integration for data storage  
- Role-based access (Admin / Passenger)  
- Validation and error handling for secure operations  
- Responsive front-end built with React
